# Clinicals 3.0 Initialization

Clinicals 3.0 was forked from the preserved Clinicals 2.0 baseline.

Clinicals 2.0 remains available in its separate repository. Clinicals 3.0 will use separate deployment and infrastructure so that continued development does not alter the preserved Clinicals 2.0 environment.

Infrastructure separation will be completed in a subsequent step. Existing runtime, deployment, authentication, API, and database configuration remains unchanged during this initialization.
